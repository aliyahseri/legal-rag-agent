# data/

Not included in the repository. `python main.py ingest` (and `POST /ingest`) read PDFs from:

```
data/
├── case_law/    # *.pdf, indexed into vector_stores/case_law_index
└── contracts/   # *.pdf, indexed into vector_stores/contracts_index
```

If both folders contain no PDFs, ingest writes 5 synthetic `.txt` documents into each folder
and indexes those instead (the same 5 documents go into both indexes).

To use the 10 synthetic PDFs instead, run `python scripts/generate_synthetic_docs.py`
(it writes to `./case_law/` and `./contracts/` at the repo root), then move them here:

```
mkdir -p data/case_law data/contracts
mv case_law/*.pdf data/case_law/
mv contracts/*.pdf data/contracts/
```

All documents are synthetic and generated by this project; none are real cases or contracts.
Delete `vector_stores/` before re-ingesting, because an existing index is never rebuilt.
